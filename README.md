# Бот розкладу пар ІПЗ-1 курс

## Що вміє бот
- Запам'ятовує обрану групу (ІПЗ-11 / 12 / 13 / 14)
- Показує розклад на сьогодні / завтра / тиждень
- Вибір конкретного дня
- Красиве оформлення з посиланнями на пари

## Як запустити

### 1. Встановити залежності
```bash
pip install -r requirements.txt
```

### 2. Запустити бота
```bash
python bot.py
```

### 3. Написати боту в Telegram
Знайди свого бота і натисни /start

## Структура
- `bot.py` — основна логіка
- `config.py` — токен і налаштування
- `data.py` — робота з розкладом
- `keyboards.py` — кнопки
- `schedule_clean_IPZ11-14.csv` — чисте розклад

## Важливо
Токен бота зараз прописаний прямо в `config.py`.  
Краще винести його в файл `.env`:

```
BOT_TOKEN=твій_токен
```

І в `config.py` він уже читається з змінної середовища.
